# Buncha Bums Fantasy Monitor

A private, non-commercial, read-only analytics tool for a single Yahoo Fantasy Football league.

## Purpose

This project retrieves authorized Yahoo Fantasy Sports data for private analysis, including:

- League settings and scoring rules
- Teams and rosters
- Standings and weekly matchups
- Player ownership and availability
- Transactions and waivers
- Draft results

## Access

The project requests read-only Yahoo Fantasy Sports API access. It does not add, drop, trade, or otherwise modify fantasy teams.

## Privacy

Yahoo Fantasy data is used only for personal league analysis and is not sold or redistributed.
